# WAVE-TRANSMISSION
This repository provides a LightGBM-based machine learning model for predicting the wave transmission coefficient of low-crested structures (LCS). LCS are commonly used in coastal and marine engineering for wave attenuation, shoreline protection, and harbor sheltering.
The model uses hydraulic, geometric, and wave-related parameters as input features to predict the wave transmission coefficient. LightGBM is adopted because of its efficiency and strong ability to handle nonlinear relationships in tabular engineering datasets.

## Main Functions

This repository includes code for:

- data preprocessing;
- LightGBM model training;
- model testing and evaluation;
- result analysis and visualization.

## Usage

Users can modify the dataset path, input features, model parameters, and training settings according to their own research needs.
